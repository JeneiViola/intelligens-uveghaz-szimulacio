# Intelligens üvegház szimuláció

Robotika tantárgyhoz készített projekt, amely egy intelligens üvegház működését modellezi Tinkercad környezetben, két Arduino Uno segítségével.

## Projekt bemutatása

A rendszer különböző szenzorokkal figyeli az üvegház környezeti állapotát. A két Arduino közötti kommunikáció lehetővé teszi a mért adatok feldolgozását és az üvegház eszközeinek vezérlését.

## Tinkercad szimuláció

[A szimuláció megnyitása](https://www.tinkercad.com/things/eSRLVXRFoE5-robotika-2-arduino-szenzor-kommunikacio?sharecode=Lqn4ym1ML6kwpIZpxg7XYpbN1rLWj-lpMYMj42dsyFo)

## Projektfájlok

- `dokumentacio/` – A beadandó részletes dokumentációja PDF-formátumban.
- `kapcsolasi_rajz/` – A rendszer kapcsolási rajza.
- `arduino_kodok/` – A két Arduino programkódja.

## Felhasznált eszközök

- Tinkercad Circuits
- 2 db Arduino Uno
- Környezeti szenzorok
- LCD-kijelző
- Vezérelhető kimeneti eszközök
